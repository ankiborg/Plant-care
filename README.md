# 🪴 Plant Care

A simple plant care tracker that helps you remember when to water your plants.

## Features

- **Add your plants** with a name, species, and how often they need water
- **See at a glance** which plants need water today, which are overdue, and which are fine
- **One-click watering** — press 💧 Water and the schedule resets
- **Automatic saving** — your plants are stored in your browser (localStorage), no account needed

## How to run it

No installation, no build step. Just open `index.html` in any web browser.

Or serve it locally:

```bash
python3 -m http.server 8000
```

then visit <http://localhost:8000>.

## Tech

Plain HTML, CSS, and JavaScript — no frameworks, no dependencies, nothing to build or break.
